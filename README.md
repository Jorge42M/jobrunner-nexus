# Nexus (JobRunner)

## Propósito del Proyecto
Nexus es una plataforma ligera diseñada para registrar, ejecutar, supervisar y controlar trabajos del sistema operativo en equipos Linux. El servicio administra comandos como procesos en segundo plano, controla la concurrencia, recupera las salidas (stdout/stderr) y permite la terminación anticipada de trabajos. Opera tanto en modo local como remoto dentro de una LAN o VPN.
